**الرابط المنشور:** [https://khalidsaif912.github.io/new/docs/calculator/?v=4](https://khalidsaif912.github.io/new/docs/calculator/?v=4)

**المسار في المشروع:** `docs/calculator/`

## 1. نظرة عامة

| البند | القيمة |
|--------|--------|
| الاسم بالعربية | حساب الكميات |
| الاسم بالإنجليزية | Quantity Calculation |
| الاسم المختصر (PWA) | الكميات |
| الوصف | حساب وتقسيم كميات الشحنات حسب رقم الشحنة (AWB) |
| اللغة / الاتجاه | عربي · RTL |
| نوع التطبيق | صفحة ويب + Progressive Web App (standalone) |
| التخزين | `localStorage` على جهاز المستخدم فقط (لا خادم بيانات) |

### ماذا يفعل التطبيق؟

1. تضيف شحنة برقم **AWB** وكمية إجمالية **QTY**.
2. تقسّم الكمية إلى **أجزاء** (Parts) على شكل باليتات مرئية.
3. يتابع التطبيق تلقائياً: **المستخدم (Used)** و**المتبقي (Remaining)**.
4. عند اكتمال التقسيم (`Remaining = 0`) تظهر إشارة نجاح وتأثير بصري خفيف.
5. البيانات تُحفظ محلياً ويمكن تثبيت الصفحة كتطبيق على الجوال أو سطح المكتب.

## 2. هيكل الواجهة

### 2.1 الهيدر

- عنوان مزدوج: **حساب الكميات** + `Quantity Calculation`.
- أزرار الإجراءات (أيقونات مسطّحة زرقاء من ملفات `icons/`):

| الزر | المعرف | الوظيفة |
|------|--------|---------|
| تحديث | `#refreshBtn` | إعادة تحميل الصفحة مع كسر الكاش (`?v=timestamp`) |
| تثبيت | `#installPwaBtn` | تثبيت كتطبيق PWA أو عرض خطوات الإضافة |
| الرئيسية | `#homeBtn` | العودة لصفحة الروستر (`getRosterHomeUrl()`) |

### 2.2 نموذج الشحنة

بطاقة `.shipment-form-card` تحتوي:

| الحقل | المعرف | ملاحظات |
|--------|--------|---------|
| رقم الشحنة | `#awb` | إدخال رقمي، اتجاه LTR |
| الكمية | `#quantity` | إجمالي القطع للشحنة |
| زر الإضافة | `#addShipmentBtn` | «إضافة / تحديث الشحنة» |

**سلوك الانهيار (Collapse):**

- بعد إضافة/تحديث ناجح تُطوى حقول AWB وQTY ويبقى زر **إضافة**.
- الضغط على **إضافة** مرة أخرى يوسّع الحقول ويركّز على AWB لإدخال شحنة جديدة بسرعة.

### 2.3 التبويبات (Tabs)

- كل شحنة = تبويب باسم الـ AWB.
- حالات لون التبويب:
  - عادي: لم يكتمل التقسيم بعد.
  - `.complete`: المتبقي = 0.
  - `.excess`: المتبقي سالب (مجموع الأجزاء تجاوز QTY).
- زر إغلاق التبويب يحذف الشحنة بعد تأكيد.

### 2.4 شبكة الأجزاء (Parts Grid)

لكل جزء:

- رقم ثلاثي الأبعاد قابل للتحرير (`.number-3d` / contenteditable).
- رسم باليت SVG تحت الرقم.
- زر حذف صغير.
- جزء شبح `+` (Ghost) يظهر فقط إذا بقي متبقي > 0 — للضغط السريع لإضافة جزء جديد.

أعلى الشبكة:

- عرض `QTY` و`AWB`.
- سطر الحالة: `Used: … | Remaining: …` مع ✓ أو ✕ حسب الحالة.

### 2.5 الفوتر

- نص الحالة `#statusText`.
- عداد الشحنات `#totalShipments`.
- زر `!` يفتح معلومات المصمم.

### 2.6 النوافذ المنبثقة

| النافذة | الغرض |
|---------|--------|
| تنبيه مخصص | رسائل التحقق والأخطاء |
| تأكيد مخصص | حذف جزء / حذف شحنة |
| تكرار الجزء | اختيار عدد التكرار 2–10 |
| مساعدة PWA | خطوات التثبيت (خصوصاً iOS) |
| معلومات المصمم | الاسم وواتساب |

## 3. سير العمل التفصيلي

### 3.1 إضافة شحنة جديدة

1. أدخل **AWB** ثم **QTY**.
2. عند كتابة 4 أرقام فأكثر في AWB ينتقل التركيز تلقائياً إلى QTY.
3. اضغط **إضافة / تحديث الشحنة** أو `Enter`.
4. يُنشأ تبويب جديد بجزء واحد فارغ (أو جاهز للتعبئة).
5. النموذج ينطوي، والتركيز ينتقل لرقم الجزء لتسريع الإدخال.

### 3.2 تحديث شحنة موجودة

- إدخال نفس الـ AWB مع كمية جديدة يحدّث `quantity` للشحنة الحالية مع الإبقاء على الأجزاء قدر الإمكان ضمن المنطق الحالي للتطبيق.

### 3.3 تعبئة الأجزاء

- انقر الرقم واكتب الكمية (أرقام فقط، حتى 6 خانات).
- يُحدَّث Used / Remaining فوراً ويُحفظ تلقائياً.

### 3.4 إضافة جزء

طرق الإضافة:

1. الضغط على الجزء الشبح `+`.
2. اختصار **الضغط المطول على مفتاح `0`** لمدة ≈ 600ms داخل حقل الجزء.
3. (عند الحاجة) منطق `addPart(awb)` من الكود — يرفض الإضافة إذا `Remaining ≤ 0`.

### 3.5 حذف جزء

- زر الحذف على الجزء → تأكيد.
- **لا يمكن حذف الجزء الأخير** في الشحنة.

### 3.6 تكرار الجزء (Long-press) — ميزة أساسية

1. اضغط مطولاً ≈ **450ms** على **العنصر كاملاً** (الرقم + البليت)، وليس على زر الحذف.
2. تظهر نافذة **تكرار الجزء** مع أزرار جاهزة:

```
2  3  4
5  6  7
8  9  10
```

3. مثال: الجزء قيمته `10` واخترت `3` → ينتج ثلاثة أجزاء كل منها `10` (المجموع 30).
4. الأرقام التي تتجاوز الكمية المتبقية تظهر **معطّلة**.
5. إذا كانت كمية الجزء 0 أو لا تكفي لتكرار مرتين، يظهر تنبيه بدل النافذة.
6. اهتزاز خفيف على الأجهزة الداعمة عند فتح النافذة.

### 3.7 اكتمال التقسيم

- عندما `Remaining === 0` لأول مرة: وميض بصري + تحديث حالة التبويب، ويُعلَّم الحقل `celebrated` حتى لا يتكرر الاحتفال.

### 3.8 حذف شحنة

- زر إغلاق التبويب → تأكيد → حذف من الذاكرة والتخزين المحلي.

### 3.9 التحديث والرئيسية

- **تحديث:** يعيد فتح نفس الصفحة مع باراميتر إصدار جديد لكسر الكاش.
- **الرئيسية:** يوجّه لروستر GitHub Pages أو مساراً نسبياً `../../` حسب بيئة التشغيل.

## 4. نموذج البيانات والتخزين

### 4.1 البنية في الذاكرة

```js
shipments[awb] = {
  quantity: number,          // إجمالي QTY
  parts: [
    { quantity: number|string, color: 'default' }
  ],
  celebrated: boolean        // تم عرض احتفال الاكتمال؟
}
```

متغيرات عامة مهمة:

- `shipments` — كل الشحنات.
- `activeTab` — الـ AWB النشط.
- `pendingRepeat` — سياق نافذة التكرار.
- `deferredPwaPrompt` — حدث تثبيت المتصفح إن وُجد.

### 4.2 المفتاح في localStorage

| المفتاح | المحتوى |
|---------|---------|
| `quantitySplitterData` | JSON: `{ shipments, activeTab, timestamp }` |

دوال الحفظ/التحميل:

- `saveData()` — عند كل تعديل جوهري.
- `loadData()` — عند فتح الصفحة؛ يعيد بناء التبويبات.
- حفظ دوري كل 60 ثانية إن وُجدت شحنات.
- حفظ عند `beforeunload`.

> **ملاحظة خصوصية:** البيانات تبقى على جهاز المستخدم فقط. مسح بيانات الموقع يحذف الشحنات المحفوظة.

## 5. التحقق من الصحة ومؤشرات الحالة

### 5.1 قواعد التحقق

| الحالة | السلوك |
|--------|--------|
| AWB فارغ | تنبيه + تركيز على الحقل |
| QTY غير صالح أو ≤ 0 | تنبيه |
| إدخال غير رقمي في الجزء | يُرفض / يُصفّى |
| إضافة جزء والمتبقي 0 | رفض |
| حذف آخر جزء | مرفوض مع تنبيه |
| تكرار بكمية 0 | تنبيه بتعبئة الكمية أولاً |
| تكرار يتجاوز المتبقي | تعطيل الأزرار أو تنبيه بالحد الأقصى |

### 5.2 الحسابات

```
Used      = مجموع كميات الأجزاء
Remaining = QTY − Used
```

| Remaining | المظهر |
|-----------|--------|
| `> 0` | متبقي طبيعي + جزء شبح `+` |
| `= 0` | ✓ نجاح · تبويب complete |
| `< 0` | ✕ خطأ (وميض) · تبويب excess |

## 6. الاختصارات والتفاعلات

| التفاعل | التفاصيل |
|---------|----------|
| `Enter` على AWB أو QTY | تنفيذ إضافة/تحديث الشحنة |
| AWB ≥ 4 أحرف | تركيز تلقائي على QTY |
| `Enter` داخل رقم الجزء | إخراج التركيز (blur) |
| ضغط مطول على `0` (~600ms) | إضافة جزء جديد |
| ضغط مطول على الجزء (~450ms) | نافذة التكرار 2–10 |
| حركة الإصبع > ~28px أثناء الضغط | إلغاء الـ long-press |
| Enter / Space على الجزء الشبح | إضافة جزء |
| قائمة السياق على الجزء | تُمنع أثناء الضغط المطول |

## 7. Progressive Web App (PWA)

### 7.1 الملفات

| الملف | الدور |
|-------|--------|
| `manifest.webmanifest` | الاسم، الألوان، الأيقونات، `standalone` |
| `sw.js` | Service Worker (إصدار `calc-qty-2026-07-25-v1`) |
| `icon-192.png` / `icon-512.png` | أيقونات التثبيت |
| `apple-touch-icon.png` | أيقونة iOS |

خصائص الـ Manifest:

- `start_url` / `scope`: `./`
- `display`: `standalone`
- `theme_color` / `background_color`: `#1976D2`
- `lang`: `ar` · `dir`: `rtl`

### 7.2 سلوك التثبيت

1. إن كان التطبيق يعمل بالفعل كـ standalone → يُخفى زر التثبيت.
2. إن أطلق المتصفح `beforeinstallprompt` → الزر يفتح نافذة التثبيت الأصلية.
3. وإلا → ورقة مساعدة:
   - **iPhone/iPad:** مشاركة → Add to Home Screen → Add.
   - **Android / سطح المكتب:** قائمة المتصفح → تثبيت التطبيق أو إضافة إلى الشاشة الرئيسية.

### 7.3 Service Worker

- لا يخزّن مستند HTML في كاش دائم (`cache: 'no-store'` للتنقل).
- ينظّف نُسخ كاش قديمة باسم يبدأ بـ `calc-qty-`.
- التسجيل من الصفحة: `navigator.serviceWorker.register('sw.js?v=1')`.

## 9. ملاحظات تقنية للواجهة

- **RTL عام** مع حقول أرقام باتجاه LTR.
- **تخطيط الجوال:** عند الشاشات الضيقة أو اللمس يصبح الهيدر/المحتوى/الفوتر نسبيين بدل الثابت؛ شبكة الأجزاء 3 أعمدة (أو عمودين جداً على الشاشات الضيقة جداً)، وسطح المكتب 5 أعمدة.
- **Safe Area:** هوامش `env(safe-area-inset-*)` للهيدر والفوتر على الأجهزة ذات النوتش.
- **ارتفاع ديناميكي:** `--header-h` و`--footer-h` عبر `updateLayoutHeights()`.
- **خطوط:** Rubik + Plus Jakarta Sans للعناوين؛ Segoe UI للنص العام.
- **تنبيهات المتصفح:** `alert` / `confirm` مُستبدلة بنوافذ مخصصة داخل الصفحة.
- **Viewport:** سكربت يصحّح عرض الجوال عند اختلاف `innerWidth` عن عرض الشاشة الفعلي.

## 12. سيناريوهات استخدام سريعة

### سيناريو أ — شحنة 30 قطعة على 3 باليتات متساوية

1. AWB مثلاً `123456` وQTY = `30` → إضافة.
2. اكتب `10` في الجزء الأول.
3. اضغط مطولاً على الجزء → اختر `3`.
4. النتيجة: ثلاثة أجزاء × 10 · Remaining = 0 · تبويب مكتمل.

### سيناريو ب — كميات غير متساوية

1. شحنة QTY = `25`.
2. أجزاء: `10` ثم `8` ثم `7`.
3. يختفي الجزء الشبح عند الوصول للصفر.

### سيناريو ج — تثبيت على الجوال

1. افتح الرابط في Chrome/Safari.
2. اضغط أيقونة التثبيت في الهيدر.
3. ثبّت من نافذة المتصفح أو اتبع خطوات المساعدة.
4. افتح التطبيق من الشاشة الرئيسية بدون شريط عنوان المتصفح.
